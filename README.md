# 卢华｜像素美术作品集

这是一个无需构建工具的静态作品集，直接打开 `index.html` 即可预览。

当前版本采用“Win98 桌面 + Egg Island 像素素材”的形式：左侧桌面快捷方式负责切换窗口，中央活动窗口展示主页、作品、项目、简历和联系信息，底部任务栏显示当前窗口。

## 页面结构

- 主页：个人定位、工作方向、成果和联系方式。
- 作品：上方显示当前选中作品的大图与说明，下方为可滚动缩略图墙，支持按角色、动画、UI/Icon、场景、系统筛选。
- 项目：《蛋岛的鸟》和 Game Jam《雾港》的项目案例位置。
- 简历：当前定位、核心能力与经历线索。
- 联系：邮件、微信、小红书和 Steam 链接占位。

## 文件

- `index.html`：页面内容、窗口结构和作品条目。
- `styles.css`：Win98 桌面、窗口、作品浏览器和响应式布局。
- `script.js`：桌面窗口切换、作品筛选、缩略图选中和详情更新。
- `theme.css`：颜色变量和少量基础主题 token。
- `assets/`：站内使用的鸟类、UI、场景和项目素材。
- `DESIGN_GUIDE.md`：后续用 Figma 或视觉方式调版时的规范。

## 预览

直接打开：

`E:\个人简历\website\index.html`

也可以在 `website` 目录启动任意静态服务器。所有资源都使用站内相对路径，不依赖 Unity 工程路径。
